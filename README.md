# Vector

256 DOM bars in a 16×16 grid each independently track your cursor through an angular spring — nearby bars snap toward you with physical weight and overshoot, distant ones follow lazily. The gradient needles grow longer and brighter as the cursor approaches, making the field feel dense and alive. Click anywhere to fire a radial burst that temporarily scrambles every bar in the field before they recover.

**Interaction:** Move cursor to orient bars · Click to fire shockwave  
**Tech:** DOM elements, CSS transforms, angular spring physics
